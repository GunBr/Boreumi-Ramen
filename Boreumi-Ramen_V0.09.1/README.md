# 보름이의 라면포차 V0.09.1

컨셉 이미지를 실제로 조작 가능한 모바일 가로형 HTML 게임으로 연결한 첫 구현 버전입니다.

## 핵심 변경
- 컨셉 완성 이미지를 통째 배경으로 사용하지 않고 하늘, 달, 도시, 강, 포장마차, 선반, 조리대, 캐릭터, 손님, 냄비, UI를 독립 레이어로 구성
- 승인된 보름이·뽀미 디자인을 독립 캐릭터로 표시
- 손님 3종이 입장할 때 나타나고 퇴장하면 사라짐
- 주문 말풍선에 메뉴명 텍스트 대신 실제 라면 일러스트 표시
- 물과 스프 버튼 제거
- 면을 드래그하면 물과 스프가 자동으로 투입되는 단계 연출
- 토핑 최대 2개
- 승인된 조합만 제조 가능
- 토핑 조합마다 냄비 이미지가 각각 변경
- 통 청양고추와 송송 썬 대파가 구별되는 레시피 이미지 사용
- 완성 냄비를 손님 주문 말풍선으로 드래그해 서빙
- 탄 음식은 냄비 클릭 시 자동 폐기
- 아이폰 가로 모드와 PC 마우스 Pointer Events 지원

## 기본 조작
1. 영업 시작
2. 면을 빈 냄비로 드래그
3. 물과 스프 자동 투입을 기다림
4. 조리 중 토핑을 최대 2개 드래그
5. 완성 냄비를 주문 말풍선으로 드래그
6. 탄 냄비는 클릭해 자동 폐기
