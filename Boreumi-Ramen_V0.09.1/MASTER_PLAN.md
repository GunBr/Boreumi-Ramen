# 보름이의 라면포차 마스터 기획서 — V0.09 반영

## 고정 방향
- 화면과 기능을 매 버전 함께 개선한다.
- AI 컨셉 이미지를 통째 배경으로 사용하지 않는다.
- 배경·보름이·뽀미·손님·냄비·음식·UI는 독립 레이어로 구현한다.
- 음식은 먹음직스럽고 축소 화면에서도 식별 가능해야 한다.
- 대파는 송송 썬 링 형태, 청양고추는 통째 형태로 표현한다.
- 뽀미는 목걸이를 착용하지 않는다.
- 물과 스프는 플레이어 UI에서 제거하고 면 투입 후 보름이가 자동 처리한다.
- 플레이어는 면과 최대 2개의 토핑만 직접 조작한다.
- 등록된 현실적인 레시피만 제조할 수 있다.
- 냄비는 조합마다 실제 음식 일러스트가 다르게 표시된다.
- 별도 폐기 버튼을 두지 않으며 탄 냄비 클릭 시 자동 폐기한다.
- 변경은 제안 → 승인 → 문서 반영 → 개발 순서로 진행한다.
