# 보름이의 라면포차 V0.10

V0.09·V0.09.1에서 발생한 패널 조각, 겹침, 시작 버튼 상태 오류를 없애기 위해 처음부터 다시 만든 안정화 기반입니다.

## 구현 범위
- 1600×900 고정 게임 무대를 화면 비율에 맞춰 통째로 축소
- 패널 시트에서 잘라낸 음식·냄비 리소스를 사용하지 않음
- 독립 SVG 냄비·면·계란·완성 라면 리소스
- 보름이와 목걸이 없는 뽀미
- 손님 1명 입장·주문·퇴장
- 냄비 1개
- 면 → 자동 물 → 자동 스프 → 계란 → 완성
- 완성 냄비를 주문 말풍선으로 드래그해 서빙
- 탄 냄비 클릭 자동 폐기
- 영업 시작 후 시작 버튼 즉시 숨김
- 모바일 가로 화면과 PC 마우스 지원

## 조작
1. 영업 시작
2. 면을 냄비로 드래그
3. 자동 물·스프 투입을 기다림
4. 조리 중 계란을 냄비로 드래그
5. 완성 냄비를 손님 말풍선으로 드래그
6. 탄 냄비는 클릭해 폐기
