# 보름이의 라면포차 V0.12

별도 설치 없이 `index.html`을 웹 서버에서 열어 플레이하는 모바일 가로형 웹 게임입니다.

V0.12는 레벨 1의 작고 따뜻한 포차 내부를 중심으로 손님 3명, 보름이·뽀미, 냄비 3개·그릴 2개·오뎅바 1개, 음식·재료 아트 시스템을 조밀하게 배치합니다. 기본 플레이 영역은 `1920×1080`이며 넓은 모바일 화면에서는 최대 `2340×1080`까지 포차 배경과 카운터가 자연스럽게 이어집니다.

Cloudflare Pages나 GitHub Pages에는 이 폴더 안의 파일들을 저장소 최상위에 업로드하세요.
