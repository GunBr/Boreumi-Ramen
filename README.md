# 보름이의 라면포차 V0.15

V0.15는 V0.14의 조리·손님 시스템을 `영업 시작 → 조리와 서빙 → 영업 종료 → 정산 → 업그레이드 → 다음 날`로 연결한 경영 시스템 버전입니다.

- 기준 플레이 영역: `1920×1080`
- 확장 가로 영역: 최대 `2340×1080`
- 하루 영업 시간: 90초
- 손님 기본 인내심: 40초
- 라면·군만두가 완성 후 타기까지: 10초
- 입력: 마우스·모바일 터치 포인터 드래그

## 하루 경영 흐름

DAY 1의 목표 금액은 10,000원이며 이후 하루마다 2,500원씩 증가합니다. 영업이 끝나면 목표 금액, 매출, 완료 주문, 놓친 손님, 폐기 음식과 만족도를 정산합니다. 매출에 목표 달성 보너스와 친절 보너스를 더한 금액이 보유 골드로 저장됩니다.

## 업그레이드

- 빠른 손놀림: 레벨마다 조리 시간 8% 단축
- 안전 불조절: 레벨마다 완성 음식이 타기까지 2.5초 증가
- 따뜻한 응대: 레벨마다 손님 인내심 5초 증가
- 단골 홍보: 레벨마다 다음 손님 방문 간격 8% 단축

각 업그레이드는 3단계까지 올릴 수 있습니다. 날짜가 올라가면 목표 금액과 손님 방문 속도가 조금씩 변하며, 목표 달성 횟수는 향후 포장마차 확장 단계에 연결됩니다.

## 저장과 초기화

현재 날짜, 보유 골드, 포장마차 레벨, 업그레이드와 누적 영업 기록은 브라우저에 자동 저장됩니다. 진행 초기화는 실수 방지를 위해 버튼을 3.5초 안에 두 번 눌러야 실행됩니다.

`index.html`을 브라우저에서 열어 실행할 수 있습니다. 로컬 파일 실행이 제한되는 브라우저에서는 간단한 로컬 웹 서버로 폴더를 열어주세요.
