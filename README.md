# 보름이의 라면포차 V0.14

V0.14는 V0.13의 조리 시스템을 손님별 복합 주문, 주류 서빙, 인내심과 만족도에 연결한 버전입니다.

- 기준 플레이 영역: `1920×1080`
- 확장 가로 영역: 최대 `2340×1080`
- 조리기구: 냄비 3개, 그릴 2개, 오뎅바 1개
- 레시피: 기본 라면, 계란 라면, 군만두, 오뎅
- 주문: 음식과 주류를 함께 요청하는 2개 항목 조합
- 손님 상태: 입장 → 대기/부분 완료 → 만족도 결정 → 결제·퇴장 또는 대기 실패
- 조리 상태: 대기 → 조리 중 → 완성 → 탄 음식/보온 → 클릭 폐기
- 여유 시간: 손님 인내심 40초, 라면·군만두 완성 후 타기까지 10초
- 입력: 마우스·모바일 터치 포인터 드래그

`index.html`을 브라우저에서 열어 실행할 수 있습니다. 로컬 보안 정책 때문에 일부 브라우저에서 파일 실행이 제한되면 간단한 로컬 웹 서버로 폴더를 열어주세요.

주문 말풍선에는 음식과 주류가 일러스트로 함께 표시되고, 인내심 막대는 말풍선 바로 아래에 붙어 항상 확인할 수 있습니다. 한 항목을 먼저 주면 완료 표시가 남고 손님은 기다리며, 모든 항목을 전달했을 때만 판매 금액이 반영됩니다. 잘못된 메뉴는 소비되지 않지만 손님의 인내심이 줄어듭니다.

소주·맥주·소맥·막걸리는 진열대에서 손님 또는 주문 말풍선으로 바로 드래그해 서빙합니다. 오뎅은 V0.13 규칙대로 타지 않고 오뎅바에서 계속 보온되며, 완성 음식과 탄 음식의 클릭 즉시 폐기도 유지됩니다.
