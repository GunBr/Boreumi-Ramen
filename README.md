# 보름이의 라면포차 V0.26.2

V0.26.2는 대화를 편하게 읽을 수 있도록 손님 대기와 음식 보관 부담을 없애고, 캐릭터 위치·재료 상점·라면 그림을 다듬은 안정화 버전입니다.

## 핵심 기능

- 기본 라면 5종과 복합 라면 4종, 군만두, 오뎅, 주류 4종
- 메뉴·레시피 수첩과 포차 레벨별 잠금 표시
- 승인된 2토핑 조합과 메뉴별 완성형 조리 일러스트
- 새 메뉴 해금 알림
- 영업 중에도 이용 가능한 재료 상점과 `+1`, `+5`, `가득` 구매
- 손님은 주문이 모두 나올 때까지 무한 대기
- 완성된 모든 음식은 타지 않고 계속 보온
- 손님·조리도구 중심에 맞춰 이동하는 보름이
- 일반 플레이와 분리된 `?dev` 개발 도구
- 모바일 가로 PWA, 오프라인 캐시, 저장 백업·복구

## 실행

- 일반 플레이: `index.html`
- 개발 도구: `index.html?dev`
- 자동 검사: `index.html?qa&silent`

로컬 파일을 직접 여는 대신 정적 웹 서버나 GitHub Pages에서 실행하는 것을 권장합니다.

## 저장 호환

V0.25와 V0.26 저장은 그대로 이어집니다. 기존 DAY, 골드, 업그레이드, 재고, 메뉴 해금, 손님 이야기가 유지됩니다.
