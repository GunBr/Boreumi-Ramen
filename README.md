# 보름이의 라면포차 V0.04

사용자 검토 내용 1~5를 우선 반영한 구조 수정 버전입니다.

## 수정 사항
1. 손님이 없는 좌석에는 아무 캐릭터·말풍선도 출력하지 않음
2. 손님 입장 시에만 캐릭터 일러스트와 주문 말풍선 표시
3. 상단 HUD 높이를 줄여 손님과 주문 영역을 가리지 않도록 조정
4. 냄비 버튼 도형을 제거하고 별도 SVG 냄비 일러스트로 교체
5. 면·스프·계란·대파·떡·김치에 개별 음식 일러스트 추가
6. 기존의 '빈자리', '다음 손님을 기다려요' 안내 문구 제거

## 참고
- 현재 손님·냄비·재료 SVG는 레이어 구조와 동작을 검증하기 위한 첫 게임용 일러스트입니다.
- 최종 아트는 승인된 고품질 스타일에 맞춰 계속 교체·정교화합니다.
