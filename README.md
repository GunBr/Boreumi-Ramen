# 보름이의 라면포차 V0.03

V0.02의 클릭 조작을 폐기하고, 승인된 드래그 앤 드롭 방식으로 수정한 버전입니다.

## 핵심 수정
- 아이폰 터치와 PC 마우스 모두 Pointer Events 기반 드래그 지원
- 재료를 냄비로 직접 드래그해 투입
- 면과 스프가 들어가면 자동으로 10초 조리 시작
- 조리 시작 후 5초 동안 토핑 추가 가능
- 토핑 최대 2개
- 완성된 냄비를 손님의 주문칸으로 드래그해 서빙
- 탄 음식은 냄비를 누르면 즉시 폐기
- 배경 확대·이동, 조명 맥동, 김과 빛 입자 애니메이션 추가
- 고정 이미지 위 버튼 느낌을 줄이기 위한 분위기 레이어 추가

## 조작
1. 영업 시작
2. 면을 냄비로 드래그
3. 스프를 같은 냄비로 드래그
4. 필요한 토핑을 냄비로 드래그
5. 완성된 냄비를 주문한 손님의 주문칸으로 드래그
