# 보름이의 라면포차 V0.05 — 구조 전면 재구축

## 이번 버전 핵심
- 기존 AI 완성 화면 이미지를 배경으로 사용하지 않음
- 사람·캐릭터·음식·냄비가 없는 별도 포장마차 배경 제작
- 승인된 보름이와 뽀미 기준 이미지에서 캐릭터 레이어 분리
- 손님은 영업 중 입장할 때만 나타나고 퇴장하면 사라짐
- 주문 말풍선은 메뉴 텍스트가 아니라 음식 일러스트 조합으로 표시
- 면·스프·계란·대파·떡·김치 일러스트 재제작
- 소주·맥주·소맥 일러스트 추가
- 김치전·계란말이·군만두·소시지 일러스트 추가
- 재료 이미지를 실제로 드래그해 냄비에 투입
- 빈 조리대에는 냄비가 없고, 첫 재료를 넣을 때 냄비가 나타남
- 완성 후 손님 주문 말풍선으로 냄비를 드래그하면 냄비가 사라지고 판매 처리

## 이름 표기
- 모든 UI와 문서에서 `보름이`로 통일
- 기존 이미지의 `보롬이` 표기는 오타로 처리
