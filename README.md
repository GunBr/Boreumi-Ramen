# 보름이의 라면포차 V0.02

첫 플레이 가능한 시제품입니다.

## 추가된 기능
- 영업 시작 후 2초 뒤 첫 손님 등장
- 손님의 라면 주문 및 인내심 감소
- 냄비 2개 선택
- 면·스프·토핑 선택
- 라면 조리 10초
- 완성 후 5초 안전시간과 2초 경고
- 완성·위험·탄 상태 발광 연출
- 주문 일치 시 판매 및 매출 반영
- 잘못된 메뉴는 서빙 불가
- 탄 음식 및 조리 음식 폐기, 재료비 차감
- 마스터 기획서 추가

## 기본 조작
1. 영업 시작
2. 냄비 선택
3. 면 + 스프 선택
4. 주문에 맞는 토핑 선택
5. 같은 냄비를 다시 눌러 조리 시작
6. 완성 후 냄비 또는 서빙 버튼으로 전달

## 아직 미구현
- 실제 캐릭터 레이어 분리
- 드래그 조작
- 안주·술·오뎅
- 뽀미 기능
- 정산·업그레이드·자동 저장
