# 보름이의 라면포차 V0.11

모바일 가로 화면 해상도와 터치 드래그 좌표를 우선 수정한 안정화 버전입니다.

## 핵심 변경
- 아이폰 가로형 화면 비율에 맞춘 1600×780 초광폭 레이아웃 자동 적용
- 브라우저 실제 표시 영역(`visualViewport`) 기준으로 게임 화면 확대
- 가로 화면에서 좌우 검은 여백 최소화
- 노치·다이내믹 아일랜드 안전영역 반영
- 드래그 이미지를 변형된 게임 무대 밖의 고정 오버레이로 이동
- 재료를 누른 손가락 위치 바로 위에서 드래그 이미지가 시작되도록 수정
- 모바일 기본 스크롤·선택·이미지 드래그 차단
- 영업 시작, 면 → 자동 물·스프 → 계란 → 완성 → 서빙 흐름 유지

## 모바일 확인 방법
1. 아이폰을 가로로 회전
2. 영업 시작
3. 면을 길게 누르지 말고 바로 냄비로 끌기
4. 자동 물·스프 투입 후 계란을 냄비로 끌기
5. 완성 냄비를 손님 주문 말풍선으로 끌기
