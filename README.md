# 보름이의 라면포차 V0.06

화면과 기능을 동시에 개선한 버전입니다.

## 화면 개선
- 밝은 보름달 광원과 따뜻한 색감 강화
- 흔들리는 등불과 달빛 애니메이션
- 보름이의 미세한 대기 움직임과 조리 상태 말풍선
- 뽀미 대기 움직임 유지
- 냄비 김, 기포, 완성·위험·탄 상태 효과

## 기능 개선
- 냄비에 들어간 재료가 텍스트가 아니라 실제 일러스트 레이어로 표시
- 면, 국물, 계란, 대파, 떡, 김치가 각각 냄비 안에 나타남
- 여러 토핑 조합도 냄비 안에서 동시에 보임
- 조리 중 국물 기포와 김 효과
- 탄 음식은 별도 폐기 버튼 없이 냄비를 클릭하면 즉시 자동 폐기
- 기존 드래그, 주문, 조리, 서빙 기능 유지
