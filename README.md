# 보름이의 라면포차 V0.13

V0.13은 V0.12에서 완성한 레벨 1 포차 아트를 그대로 보존하고, 실제 플레이의 중심인 조리 시스템을 정식 구조로 교체한 버전입니다.

- 기준 플레이 영역: `1920×1080`
- 확장 가로 영역: 최대 `2340×1080`
- 조리기구: 냄비 3개, 그릴 2개, 오뎅바 1개
- 레시피: 기본 라면, 계란 라면, 군만두, 오뎅
- 상태 흐름: 대기 → 조리 중 → 완성 → 탄 음식 → 폐기
- 입력: 마우스·모바일 터치 포인터 드래그

`index.html`을 브라우저에서 열어 실행할 수 있습니다. 로컬 보안 정책 때문에 일부 브라우저에서 파일 실행이 제한되면 간단한 로컬 웹 서버로 폴더를 열어주세요.

주류 4종은 V0.12의 진열 아트를 유지하며, 주문·판매 기능은 다음 손님/주문 시스템 버전에서 연결할 예정입니다.
