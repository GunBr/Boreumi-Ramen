# 보름이의 라면포차 V0.23

V0.23은 V0.22의 가로 PWA와 독립 튜토리얼을 유지하면서 실제 아이폰 플레이에 필요한 터치, 로딩, 오프라인 업데이트와 저장 복구를 안정화한 버전입니다.

## V0.23 핵심

- 아이폰 가로·긴 가로·세로 시작 회전 화면 대응 보강
- 회전·화면 크기 변경 시 Visual Viewport 기준으로 무대와 드래그 좌표 재계산
- 작은 도움말·소리 버튼의 실제 터치 영역을 약 44px로 확장
- 모바일 데이터 관리 화면 추가
- 오프라인 리소스 저장 진행률 표시
- 새 버전 발견, `지금 적용`, 자동 재실행 업데이트 흐름 추가
- 저장 기록 자동 백업과 손상 시 자동 복구
- 진행 상황 JSON 내보내기·불러오기
- 튜토리얼 종료 후 실제 첫 영업 시작 버튼 강조
- 핵심 이미지 24개를 4개씩 병렬로 준비해 시작 로딩 단축
- 승인된 게임 일러스트 64개를 무손실 WebP로 전환

## 리소스 최적화

그림의 픽셀과 투명 배경을 유지하는 무손실 WebP를 사용했습니다.

- 실행 일러스트: 약 41.85MiB → 29.83MiB
- 전체 게임 폴더: 약 52.57MiB → 40.56MiB
- 전체 약 12.01MiB, 22.8% 감소

## 모바일 데이터 관리

게임의 `?` 버튼을 누르면 도움말 아래에서 다음 기능을 사용할 수 있습니다.

- 오프라인 저장 진행 상황 확인
- 최신 버전 확인
- 현재 진행 상황을 JSON 파일로 백업
- 이전에 백업한 JSON 파일 불러오기
- 독립 연습 포차 다시 보기

실제 영업 중에는 진행 충돌을 막기 위해 저장 파일 불러오기가 잠깁니다.

## 아이폰 설치

이 폴더의 내용물을 GitHub Pages 같은 HTTPS 주소로 배포한 뒤 아이폰 Safari에서 `공유 → 홈 화면에 추가`를 선택합니다. 자세한 과정은 `IPHONE_PWA_INSTALL.md`에 정리했습니다.

## 개발 실행

서비스 워커는 `file://`에서 작동하지 않습니다. 개발 중에는 이 폴더를 `localhost`로 열고, 아이폰 배포 시에는 HTTPS 호스팅을 사용해야 합니다.
