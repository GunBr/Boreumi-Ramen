# 보름이의 라면포차 V0.16

V0.16은 V0.15 경영 시스템 위에 BGM, 효과음, 모바일 진동, 조리 김·열기와 상태별 파티클을 연결한 연출 시스템 버전입니다.

- 기준 플레이 영역: `1920×1080`
- 확장 가로 영역: 최대 `2340×1080`
- 하루 영업 시간: 90초
- 손님 기본 인내심: 40초
- 라면·군만두가 완성 후 타기까지: 10초
- 입력: 마우스·모바일 터치 포인터 드래그와 짧은 클릭

## 주요 조작

- 재료·토핑 → 해당 조리기구로 드래그
- 완성 음식 → 손님 캐릭터나 주문 말풍선으로 드래그
- 주류 → 손님 캐릭터나 주문 말풍선으로 드래그
- 완성 음식·탄 음식 → 짧게 클릭하거나 터치해 즉시 폐기
- 음표 버튼 → BGM·효과음·진동 켜기/끄기

브라우저의 자동 재생 정책에 따라 소리는 영업 시작 또는 음표 버튼을 처음 누른 뒤 활성화됩니다. `index.html`을 브라우저에서 열어 실행할 수 있으며, 로컬 파일 실행이 제한되면 폴더를 로컬 웹 서버로 열어주세요.
