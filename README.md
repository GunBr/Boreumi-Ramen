# 보름이의 라면포차 V0.26

V0.26은 V0.25의 재료 재고를 실제 메뉴 조합과 구매 흐름으로 확장한 버전입니다.

## 핵심 기능

- 기본 라면 5종과 복합 라면 4종, 군만두, 오뎅, 주류 4종
- 메뉴·레시피 수첩과 포차 레벨별 잠금 표시
- 승인된 2토핑 조합과 조리 중 복수 토핑 시각화
- 새 메뉴 해금 알림
- 재료별 `+1`, `+5`, `가득` 구매와 전체 보충
- 일반 플레이와 분리된 `?dev` 개발 도구
- 모바일 가로 PWA, 오프라인 캐시, 저장 백업·복구

## 실행

- 일반 플레이: `index.html`
- 개발 도구: `index.html?dev`
- 자동 검사: `index.html?qa&silent`

로컬 파일을 직접 여는 대신 정적 웹 서버나 GitHub Pages에서 실행하는 것을 권장합니다.

## 저장 호환

V0.25 저장은 V0.26 첫 실행 때 자동으로 이전됩니다. 새 메뉴 해금 기록은 현재 포차 레벨에 맞게 생성되며 기존 DAY, 골드, 업그레이드, 손님 이야기는 유지됩니다.
