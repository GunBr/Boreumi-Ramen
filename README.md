# 보름이의 라면포차 V0.25

V0.25는 기존 모바일 가로 PWA와 무한 DAY 구조를 유지하면서 `재료 재고 → 조리 → 판매 → 정산 후 보충`으로 이어지는 재료·메뉴 시스템을 추가한 버전입니다.

## 이번 버전 핵심

- 계란·대파·김치·치즈 토핑이 완성 전 조리 중 냄비에도 즉시 표시됩니다.
- 기본 라면, 계란 라면, 대파 라면, 김치 라면, 치즈 라면을 서로 다른 메뉴와 완성 일러스트로 구분합니다.
- 재료와 주류에 실제 재고 수량을 표시하고, 사용한 만큼 즉시 차감합니다.
- 포차 레벨에 따라 대파(LV.2), 김치(LV.3), 치즈(LV.4)가 순서대로 해금됩니다.
- 정산 화면의 재료 상점에서 부족한 재료를 목표 재고까지 한 번에 보충할 수 있습니다.
- HUD, 재료 이름, 수량, 도움말, 정산·업그레이드 화면 글자를 확대하고 긴 금액도 한 줄로 유지합니다.

## 실행

`index.html`을 정적 웹 서버 또는 GitHub Pages에서 실행합니다. iPhone에서는 Safari의 홈 화면에 추가한 뒤 가로 화면으로 플레이하는 구성을 권장합니다.

## 데이터 호환

V0.24 이하 저장 기록은 V0.25 첫 실행 시 자동으로 이어받습니다. 새 재료 재고는 각 재료의 기본 목표 수량으로 초기화됩니다.
