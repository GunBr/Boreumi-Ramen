# 보름이의 라면포차 V0.26.9

V0.26.9는 손님 식사 표현과 모바일 HUD를 정돈하고 장시간 영업 성능을 다듬은 버전입니다. 식사 중에는 시간이나 먹는 동작 대신 주문한 음식과 주류가 손님 앞 테이블에 놓이며, 뽀미는 새 네발 보행 4프레임으로 천천히 주류를 자동 서빙합니다.

## 핵심 기능

- 기본 라면 5종과 복합 라면 4종, 군만두, 오뎅, 주류 4종
- 손님 주문이 모두 끝날 때까지 무한 대기하며 완성 음식도 타지 않고 계속 보온
- 포장 주문도 시간제한 없이 완료할 때까지 대기
- 완료한 포장 주문은 30초 뒤에 다음 주문 접수
- 손님은 서빙 완료 후 10초 동안 주문한 음식·주류를 앞 테이블에 놓고 식사한 뒤 퇴장
- 손님 퇴장 후 같은 좌석의 다음 손님은 5초 뒤 입장
- 포차 LV.5까지 최대 좌석 5석으로 유지
- 영업 중에도 이용 가능한 재료 상점과 `+1`, `+5`, `가득` 구매
- 영업 중 발생한 매출이 즉시 보유 금액에 반영되어 바로 재료 구매 가능
- 손님·조리도구 중심을 따라 정확히 이동하는 보름이
- 같은 날 같은 손님의 대화는 한 번만 표시되며, 손님 아래 반투명 말풍선을 `○` 버튼으로 닫을 수 있음
- 해금된 음식 메뉴를 한 바퀴씩 고르게 섞어 주문하는 랜덤 메뉴 방식
- 목표 금액 없이 계속 누적되는 총 누적 매출
- 상단 HUD의 `포차 레벨 | 총 누적 금액 | 보유 금액 | 남은 시간 | 현재 매출 | 오늘 손님` 일렬 표시
- 손님 하체를 자연스럽게 가리고 화면 양끝까지 이어지는 수납형 원목 손님 테이블
- 테이블 수납칸에 소스통·꼬치·젓가락·수저·그릇·술병을 자연스럽게 배치
- 오뎅 꼬치가 3→2→1로 줄고 마지막 서빙 뒤 재료 1개를 사용해 자동으로 3개 보충되는 오뎅바
- 군만두도 3→2→1로 줄고 마지막 서빙 뒤 재료 1개를 사용해 자동으로 3개 보충되는 만두 그릴
- 뽀미가 손님 테이블을 왕복하며 손님 앞에서 주류만 자동 서빙
- 뽀미의 자연스러운 네발 보행 4프레임 애니메이션
- 하단 주류 진열대를 없애고 우측 음소거 버튼 아래에 주류 재고 수량만 표시
- 하단 라면 재료 5종과 안주 2종을 넘김 버튼 없이 한 줄에 모두 표시
- 계란은 기존 깨기 동작을 유지하고, 대파·김치·치즈는 집게 동작으로 투입
- 소주·맥주·소맥·막걸리 판매가 각각 1,000원 인상
- 간판·HUD와 같은 윗선에서 시작하는 우측 상단 세로 도구 버튼
- 확대된 포장 주문판과 라면·음식·포장 그림
- 일시정지 중 총 누적 매출·오늘 매출·보유 금액·손님·완료 주문을 보여주는 영업일지
- 전날 완성된 오뎅을 다음 영업 시작 때 빈 조리 상태로 초기화
- 좌석 좌표 캐시, GPU 이동, 이펙트 수 제한, 완료 타이머 정리로 손님·음식이 많을 때의 렉 완화
- 상향된 조리도구·포차 레벨업 비용
- 라면 그릇 속 보름달과 수증기를 담은 새 간판 및 같은 그림의 PWA 앱 아이콘
- 면과 더 잘 구분되는 짙은 적색 김치라면 3종 그림
- 일반 플레이와 같은 화면을 사용하는 `?dev` 개발 도구
- 모바일 가로 PWA, 오프라인 캐시, 저장 백업·복구

## 실행

- 일반 플레이: `index.html`
- 개발 도구: `index.html?dev`
- 자동 검사: `index.html?qa&silent`

로컬 파일을 직접 여는 대신 정적 웹 서버나 GitHub Pages에서 실행하는 것을 권장합니다.
