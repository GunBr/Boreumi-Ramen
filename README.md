# 보름이의 라면포차 V0.01

모바일 웹 가로모드와 PC 웹에서 실행되는 첫 UI 시안입니다.

## 이번 버전
- 승인된 포장마차 콘셉트 이미지를 배경으로 적용
- 아이폰 가로모드 대응 및 세로모드 회전 안내
- 상단 HUD
- 손님 자리 3개
- 냄비 3개 / 그릴 2개 / 오뎅통 / 완성품 보관함 배치
- 하단 재료·술·안주 UI
- 보름달 영업 시작 버튼
- 3분 타이머, 일시정지, 설정 기본 동작

## Netlify 배포
압축을 푼 뒤 폴더 안의 모든 파일과 폴더를 GitHub 저장소 최상위에 업로드하세요.
`index.html`이 저장소 첫 화면에 보여야 합니다.
