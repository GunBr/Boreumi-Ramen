# 보름이의 라면포차 V0.21

V0.21은 V0.20의 포장 주문·완성대와 무한 DAY 성장 시스템을 그대로 유지하면서, 아이폰 홈 화면에 설치해 실행할 수 있는 PWA 버전으로 전환한 빌드입니다.

## V0.21 핵심

- 홈 화면 설치용 웹 앱 매니페스트 추가
- 보름달 간판을 사용한 180/192/512px 앱 아이콘 추가
- 아이폰 홈 화면 실행 시 브라우저 주소창이 없는 전체화면 앱 모드 사용
- 설치형 앱의 기본 화면 방향을 가로로 지정
- 지원 기기에서는 Screen Orientation API로 가로 잠금을 한 번 더 요청
- 기존의 `가로 모드로 돌려주세요` 가림 화면 제거
- 노치·다이내믹 아일랜드를 위한 좌우 안전영역 적용
- 서비스 워커를 통한 게임 화면과 전체 런타임 에셋 오프라인 저장
- V0.20 저장 데이터 자동 이전

## 아이폰에서 설치하기

PWA 기능은 파일을 압축 해제해 직접 여는 방식이 아니라 HTTPS 주소에서 실행해야 합니다. GitHub Pages 등에 V0.21 폴더의 내용물을 올린 뒤 아이폰에서 해당 주소를 엽니다.

1. 아이폰 Safari에서 게임의 HTTPS 주소를 엽니다.
2. 하단의 공유 버튼을 누릅니다.
3. `홈 화면에 추가`를 선택합니다.
4. 홈 화면에 생긴 `라면포차` 아이콘으로 실행합니다.

자세한 배포·설치 순서는 `IPHONE_PWA_INSTALL.md`에 정리했습니다.

## 가로 화면 동작

`app.webmanifest`에서 앱 방향을 `landscape`로 지정했습니다. 홈 화면에 설치한 상태로 실행하면 지원되는 아이폰에서 가로 앱으로 열리며, 실행 중에도 가능한 경우 가로 잠금을 요청합니다.

웹 표준의 화면 방향 설정은 최종적으로 iOS 정책과 사용자의 회전 잠금 설정을 따릅니다. 모든 아이폰에서 운영체제 수준의 강제 고정이 필요한 경우 다음 단계에서 Capacitor와 Xcode를 사용하는 네이티브 앱 포장이 필요합니다.

## 오프라인 실행

첫 온라인 실행에서 게임 화면과 이미지가 기기에 저장됩니다. 저장이 끝난 뒤에는 서버 연결이 끊겨도 설치된 앱을 다시 열 수 있습니다. 새 버전을 배포하면 서비스 워커가 이전 V0.21 캐시를 새 빌드로 교체합니다.

## 기존 게임 기능

- 모바일 가로 기준 내부 무대 1920×1080, 성장 시 최대 2340×1080
- 포차 LV.1~5 성장과 최대 좌석 10개·손님 후보 18명
- 포차 LV.2부터 포장 주문, LV.3부터 완성대
- 조리·서빙·포장·완성대 드래그와 짧게 클릭해 즉시 폐기
- 포장 주문 인내심·실패 차감·레벨별 판매 보너스
- 조리도구 LV.1~5와 유료 포차 확장

## 개발 실행

서비스 워커는 `file://`에서 작동하지 않습니다. 개발 중에는 이 폴더를 `localhost`로 열고, 아이폰 배포 시에는 HTTPS 호스팅을 사용해야 합니다.
