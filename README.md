# 보름이의 라면포차 V0.22

V0.22는 V0.21 PWA를 바탕으로 모바일 첫 실행, 독립 튜토리얼, 리소스 로딩 경험을 다듬은 버전입니다. V0.21까지의 무한 DAY 성장, 포장 주문, 완성대, 조리도구·포차 업그레이드와 저장 데이터는 그대로 이어집니다.

## V0.22 핵심

- 세로로 열린 모바일 화면에서도 게임 전체를 가로 무대로 회전해 화면을 가득 채우는 PWA 대체 처리
- 매니페스트의 가로 방향 설정과 지원 환경의 화면 방향 잠금 요청 유지
- 회전 상태에서도 터치·드래그 좌표를 게임의 가로 좌표로 변환
- 실제 DAY와 분리된 `연습 포차` 튜토리얼 추가
- 튜토리얼 동안 DAY 시간, 손님 인내심, 매출과 저장 기록 정지
- 튜토리얼 주문을 `기본 라면 + 소주`로 고정해 안내 순서와 실제 주문 일치
- 리소스·저장 데이터·글꼴·PWA 준비 상태를 확인하는 시작 로딩 화면 추가
- 핵심 이미지 24개를 먼저 불러온 뒤 게임 화면으로 전환
- V0.21 저장 데이터 자동 이전

## 아이폰에서 설치하기

PWA는 파일을 직접 여는 방식이 아니라 HTTPS 주소에서 실행해야 합니다. GitHub Pages 등에 이 폴더의 내용물을 올린 뒤 아이폰 Safari에서 주소를 여세요.

1. Safari의 공유 버튼을 누릅니다.
2. `홈 화면에 추가`를 선택합니다.
3. 홈 화면의 `라면포차` 아이콘으로 실행합니다.
4. 처음 한 번은 인터넷에 연결한 상태로 로딩이 끝날 때까지 기다립니다.

자세한 과정은 `IPHONE_PWA_INSTALL.md`에 정리했습니다.

## 가로 화면 동작

설치형 앱은 가로 방향을 우선 요청합니다. iOS가 운영체제 화면 방향 잠금을 허용하지 않는 상황에서도 게임을 작은 가로 창으로 축소하지 않고, 1920×1080 논리 무대 전체를 기기 화면에 맞춰 회전합니다. 이 상태에서는 휴대폰을 가로로 잡으면 게임이 처음부터 화면 전체에 바르게 보입니다.

웹 앱이 아이폰의 운영체제 방향 자체를 모든 상황에서 강제로 바꾸는 것은 iOS 정책과 사용자의 회전 잠금 설정에 제한됩니다. 운영체제 수준의 예외 없는 가로 고정이 필요하면 이후 Capacitor/Xcode 네이티브 포장이 필요합니다.

## 튜토리얼

첫 실행 시 실제 영업과 분리된 연습 포차가 열립니다. 주문 확인, 면 조리, 완성된 라면 서빙, 소주 서빙을 차례로 연습합니다. 연습 중에는 시간과 인내심이 줄지 않으며 매출·DAY·단골·통계에 저장되지 않습니다. `영업 화면으로`를 누른 뒤 실제 영업을 시작할 수 있습니다.

## 개발 실행

서비스 워커는 `file://`에서 작동하지 않습니다. 개발 중에는 이 폴더를 `localhost`로 열고, 아이폰 배포 시에는 HTTPS 호스팅을 사용해야 합니다.
